# Contrastive Datasets for Audio ML

## Overview
High-quality audio dataset curation and preprocessing workflows optimized for contrastive audio-language model pretraining (CLAP) and fine-tuning.

## Methodologies
- **Acoustic Recording & Curation**: Studio and field recordings engineered with strict Signal-to-Noise Ratio (SNR) benchmarks and acoustic control.
- **Audio Processing Pipeline**: Automated segmentation, peak normalization, silence truncation, and spectral validation.
- **Semantic Textual Alignment**: Multi-tiered taxonomy annotation incorporating source metadata, acoustic texture descriptors, and emotional valence.
- **Model Training Support**: Downstream alignment validation for text-to-audio and audio-to-text retrieval evaluation.
