# Del Otro Lado

## Overview
**Del Otro Lado** is an interactive, multisensory art installation that explores themes of border crossing, human migration, cultural displacement, and physical vulnerability.

## Technical & Artistic Execution
- **Embedded Architecture**: Dual Arduino & Raspberry Pi hardware control units managing high-frequency sensor readings (proximity, pressure, touch).
- **Electromechanical Automation**: Custom mechanical actuators and physical barriers reacting in real time to spectator movement.
- **Dynamic Narrative Soundscapes**: Multi-channel spatial audio composition designed to elicit psychological immersion and tension.
- **Sensory Interaction**: Custom hardware triggering audio-visual changes based on participant behavior and proximity.
